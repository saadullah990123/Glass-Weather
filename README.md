# 🌤️ Glass Weather App

A modern, responsive weather application built with HTML5, CSS3 glassmorphic design, and JavaScript (Fetch API) using the OpenWeatherMap API.

## ✨ Features

- 🌡️ **Live Weather Updates:** Shows real-time temperature, weather conditions, and location.
- 🎨 **Glassmorphism UI:** Translucent frosted-glass card with dynamic blur backdrop.
- 🔍 **City Search:** Search weather for any city worldwide using the search bar or by pressing `Enter`.
- 📊 **Detailed Metrics:** Tracks "Feels Like", Humidity, Wind Speed, and Atmospheric Pressure.
- 📱 **Responsive Design:** Optimized for both desktop and mobile screen layouts.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **API:** [OpenWeatherMap API](https://openweathermap.org/api)
- **Design Style:** Glassmorphism UI
